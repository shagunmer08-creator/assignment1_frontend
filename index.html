01 — about

A bit about me

SM

Linux desktop, permanently mid-rice.

HTML CSS JavaScript Git Hyprland Linux

I'm Shagun — a frontend developer who spends about as much time tuning my own desktop environment as I do shipping interfaces for other people. I run CachyOS with Hyprland, chasing a frosted-glass, dark-mode-everywhere aesthetic across terminal, bar, and lock screen — which, unsurprisingly, bled straight into how I designed this site.

On the browser side I care about the same things: clear hierarchy, restrained motion, and interfaces that feel considered rather than assembled from a template. I'm currently digging into local LLM workflows alongside frontend work, tying automation into how I build.
